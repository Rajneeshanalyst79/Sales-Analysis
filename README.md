# 📊 Sales Data Analysis – Jupyter Notebook

This repository contains a detailed sales data analysis performed using Python in a Jupyter Notebook. The goal of the project is to uncover key insights from sales data to help inform business decisions.

File Included

- `Sales analysis2.ipynb` – The main Jupyter Notebook file with all analysis, code, and visualizations.
Project Objectives

The notebook answers important business questions, including:

- What month had the highest sales?
- What time should advertisements be displayed for peak sales?
- What city had the highest number of orders?
- What products are most frequently bought together?
- Which products are sold the most and why?

Key Features

- Data cleaning and formatting using `pandas`
- Grouping and aggregation with `.groupby()`
- Time-based sales trend analysis
- Combination analysis using `itertools.combinations` and `collections.Counter`
- Data visualizations using `matplotlib` and `seaborn`

Technologies Used

- Python 3
- Jupyter Notebook
- pandas
- matplotlib
- seaborn
- itertools
- collections

 How to Use

1. Clone the repository or download the `.ipynb` file.
2. Open it in Jupyter Notebook, JupyterLab, or VS Code with a Python environment.
3. Run each cell step-by-step.
4. Make sure the original sales CSV file is available in the same directory if needed.

 Output

The notebook provides:
- Monthly and hourly sales charts
- Bar plots of top-performing products and cities
- Insights on frequently bundled products
